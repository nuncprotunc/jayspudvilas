Navigation Bar CSS Fix

❌ Before (Broken)

Inconsistent Styling
Law Education Civic-Tech Contact
Problem: The active navigation item uses border-radius: var(--radius-sm) which equals only 10px, creating a slightly rounded rectangle instead of a proper pill shape.

Broken CSS:

.global-nav__link--active { border-radius: var(--radius-sm); /* Only 10px - not pill-shaped! */ border-bottom: 2px solid var(--blue-medium); }
↓

✅ After (Fixed)

Consistent Pill Shape
Law Education Civic-Tech Contact
Solution: Use border-radius: 9999px !important to create a perfect pill shape, and remove the bottom border for a cleaner look. The !important ensures this overrides any other styles.

Fixed CSS:

.global-nav__link--active { border-radius: 9999px !important; /* Perfect pill! */ border-bottom: none !important; /* Clean edges */ box-shadow: 0 0 0 1px rgba(59, 130, 246, 0.4) !important; }

📋 Quick Copy-Paste Fix

Find this CSS in your @media (max-width: 720px) section and replace it:

Replace this:

.global-nav__link[aria-current="page"], .global-nav__link--active { border-radius: var(--radius-full); border-bottom-width: 0; box-shadow: 0 0 0 1px rgba(59, 130, 246, 0.4); }

With this:

.global-nav__link[aria-current="page"], .global-nav__link--active { border-radius: 9999px !important; border-bottom: none !important; box-shadow: 0 0 0 1px rgba(59, 130, 246, 0.4) !important; }
Apply to both files:
  • index.html (main homepage)
  • education/index.html (Education Dashboard)
